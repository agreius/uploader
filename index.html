Install

Tanpa Arduino IDE

Cukup browser dan kabel USB. Tidak perlu install aplikasi atau driver.

Laptop / PC

Chrome · Edge
  1. Colok ESP32-C3 ke laptop dengan kabel USB-C data.
  2. Klik Install firmware, pilih port (USB JTAG, ttyACM, atau COM), lalu Connect.
  3. Tunggu sekitar 1 menit, lalu tekan RESET di board.

HP Android

Chrome
  1. Sambungkan board ke HP dengan kabel OTG (USB-C ke USB-C, atau adaptor OTG).
  2. Buka halaman ini di Chrome, ketuk Install firmware, lalu izinkan akses USB.
  3. Jangan kunci layar sampai selesai, lalu tekan RESET.

Gagal install?
  • Port tidak muncul: ganti kabel. Banyak kabel hanya untuk mengecas.
  • Gagal tersambung: tahan BOOT, tekan lalu lepas RESET, lepas BOOT, lalu coba Install lagi.
  • ESP32-C3 baru dan laptop berbunyi terus (port muncul-hilang): biarkan tetap tercolok USB, tekan dan tahan RESET + BOOT bersamaan sekitar 10 detik, lepas RESET dulu lalu BOOT, kemudian klik Install lagi.
  • Jangan menahan Tombol 2 (GPIO8) saat install.
  • Tutup aplikasi lain yang memakai port, misalnya Arduino IDE atau Serial Monitor.
  • HP Android: pastikan fitur OTG aktif (di beberapa HP ada di Pengaturan).
  • Linux: jalankan sudo usermod -aG dialout $USER, lalu logout dan login lagi.
  • iPhone/iPad belum bisa karena Safari tidak mendukung akses USB.

SD Card

Siapkan SD card

Animasi, lagu, dan pesan disimpan di microSD. Salin nama.bin + nama.wav ke folder /anim, lalu buka menu Animasi: langsung muncul, tanpa install ulang. Isi SD card juga bisa dilihat, ditambah, dan dihapus langsung dari web lewat kabel USB (laptop atau HP Android), tanpa mencabut kartu.

Isi SD card siap pakai

Format kartu ke FAT32, ekstrak file zip, lalu salin semua isinya ke kartu.
